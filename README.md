# Motion Lab

Browser-based motion experiments. No build tools required.

- `index.html`: project index
- `grps-particles/index.html`: GRPS particle logo demo (self-contained)

Publish with GitHub Pages from `main` branch, root `/`.

## てくまくコンパクト

`magic-compact/`: Three.js の魔法のコンパクト。開閉、回転、色替え、音、光の演出に対応。WebGL が使えない場合は簡易表示になります。

静的 HTTP サーバーで配信してください。Three.js r170 は同梱済み（MIT、`magic-compact/THREE-LICENSE.txt`）。
